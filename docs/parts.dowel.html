Function Reference: parts.dowel

parts: P = parts.dowel ('data')

parts: P = parts.dowel ('data', D)

parts: S = parts.dowel ('solid', D, L)

parts: S = parts.dowel (…, Name, Value)

Parallel dowel pins to ISO 8734, hardened.

P = parts.dowel ('data') returns every diameter in the catalogue as a struct array, smallest first. P = parts.dowel ('data', D) returns the one of diameter D millimetres, with the lengths in stock. Nothing is built.

S = parts.dowel ('solid', D, L) builds the pin of diameter D as a solid.Shape L long, whether or not that length is in stock: its axis on the z axis, from z = 0 to L.

Name/Value pairs:

'Detailed'
For 'solid': true chamfers both ends c along the axis at 15 degrees. By default (false) the pin is a plain cylinder.

Each diameter is a struct with these fields, lengths in millimetres:

dnominal diameter, toleranced m6
cthe chamfer at each end, approximate
lthe lengths in stock, a row vector
makerthe maker
articlethe maker’s article number
sourcethe catalogue and page the pin was read from

The catalogue

REYHER, The Catalogue, edition 2020.04, English, pages 374 and 375: article 08734.001, steel, type A, through-hardened, every diameter ISO 8734 defines, 1 to 20 mm, with the lengths in stock. Left out: the 14 mm pin REYHER also sells, a diameter ISO 8734 does not define. The pins REYHER sells under DIN 6325, which ISO 8734 replaced, are not included.

The chamfer c from Table 1 of ISO 8734:1997, as adopted word for word in IS 6689:2003, and REYHER’s Technical Information (2019, TI-116).
